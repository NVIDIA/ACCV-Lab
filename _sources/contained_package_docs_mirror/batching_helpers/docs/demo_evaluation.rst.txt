Demo & Evaluation
=================

A :doc:`demo showcasing the integration <../../../demo_docs/streampetr/batching_helpers/index>`
of the ``batching-helpers`` package in a StreamPETR training setup is available.
The demo contains a step-by-step tutorial on how to integrate the ``batching-helpers`` package,
as well as an :doc:`evaluation <../../../demo_docs/streampetr/batching_helpers/evaluation>`,
showing the performance impact of the batching optimizations (and containing instructions on how to run the 
experiments yourself).
