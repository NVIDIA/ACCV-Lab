# Auto Labeling

Demonstrate how to use ACCV-Lab to accelerate an auto-labeling pipeline, with
a concrete example based on StreamPETR for calibrated multi-camera driving videos.

See the [application documentation](../../docs/application_docs/auto_labeling/index.rst)
for setup, input requirements, inference, visualization and tests. The
[performance evaluation](../../docs/application_docs/auto_labeling/index.rst#performance)
contains the CPU JPEG comparison and pipeline ablations.
