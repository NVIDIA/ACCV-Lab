Docker Setup & Running StreamPETR

Preparing the Docker Image

The Dockerfile at demos/streampetr/docker/Dockerfile installs the dependencies for ACCV-Lab and StreamPETR. ACCV-Lab itself must then be installed from the repository, as described below.

Build the image with the demo’s build script. Setting TAG explicitly gives the image the name used in the run command below; the script otherwise defaults to accvlab.

# From the root of the repository
cd demos/streampetr/docker
TAG=streampetr:latest bash run_docker_build.sh

Running the Docker Container

Replace the host paths below with your ACCV-Lab checkout and prepared NuScenes dataset directory. All Docker options, including mounts, must come before the image name.

docker run -it \
  --gpus=all --ipc=host \
  --runtime=nvidia -e NVIDIA_DRIVER_CAPABILITIES=all \
  -v /path/to/ACCV-Lab:/ACCV-Lab \
  -v /path/to/ACCV-Lab/demos/streampetr:/streampetr \
  -v /path/to/nuscenes:/data/nuscenes \
  -w /streampetr \
  streampetr:latest bash

Important

Mount the demo at /streampetr and the full ACCV-Lab repository at /ACCV-Lab. The training script uses both paths: the latter provides the DALI Pipeline Framework example imported by the demo. Both mounts must refer to the same checkout.

The provided configurations expect the prepared dataset under /data/nuscenes/. The reference loader reads camera paths stored in the converted .pkl files verbatim. The documented conversion command stores absolute paths, so the dataset must be available at the same in-container path during conversion and training. Regenerate the files if that path changes.

To use another location, update data_root in the configuration files. DALI uses this same root; its NuScenes version is set separately as data_loading_config.nuscenes_version. See Running the Demos for data-preparation guidance.

See also

See the ACCV-Lab Docker Guide for NVIDIA Container Toolkit setup and additional runtime options.

Installing ACCV-Lab in the Container

If ACCV-Lab is not already installed from this checkout, follow the Installation Guide. With the repository’s Git submodules initialized, the standard installation command inside the container is:

cd /ACCV-Lab
./scripts/install_local.sh
cd /streampetr

Then follow the configuration guidance and commands in the evaluation section of the demo you want to run. For example, see the Batching Helpers evaluation or the DALI Pipeline Framework evaluation.

Running Regression Tests

The demo’s regression tests are separate from the repository’s core package tests. After installing ACCV-Lab, run them inside the prepared StreamPETR container:

bash /streampetr/tools/run_unit_tests.sh

The script runs demos/streampetr/tests/ with pytest. Additional pytest options can be passed to the script, for example:

bash /streampetr/tools/run_unit_tests.sh -v -k sampling

The tests do not require the NuScenes dataset. CUDA-dependent tests are skipped when no GPU is available; use the GPU-enabled container to run the full suite. Some tests also skip when their optional dependencies are unavailable. Pass -ra to list skipped tests and their reasons.

These tests check correctness; they do not run training-performance evaluations. For performance measurements, follow the Batching Helpers evaluation or DALI Pipeline Framework evaluation page.
