Batching Helpers Demo
=====================

This demo shows how to use ``accvlab.batching_helpers`` to batch the matching and loss computations
in StreamPETR.

.. seealso::

   See the :doc:`evaluation` for measured speedups, the experiment setup and commands to compare
   the baseline and batched implementations.
