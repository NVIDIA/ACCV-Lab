Demo & Evaluation
=================

A :doc:`demo showcasing the integration <../../../demo_docs/streampetr/dali_pipeline_framework/index>`
of the ``dali-pipeline-framework`` package in a StreamPETR training setup is available.
The demo contains a step-by-step tutorial on how to integrate the
``dali-pipeline-framework`` package, as well as an
:doc:`evaluation <../../../demo_docs/streampetr/dali_pipeline_framework/evaluation>`,
showing the performance impact of using the DALI Pipeline Framework (and containing
instructions on how to run the experiments yourself).
